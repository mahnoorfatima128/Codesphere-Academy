# CodeSphere Academy

A responsive 3-page business website for a fictional coding academy, built using **HTML5, CSS3, and Vanilla JavaScript**. The project follows a mobile-first approach and demonstrates responsive design, reusable components, and interactive front-end features without using any frameworks.

## Live Demo

🔗 https://mahnoorfatima128.github.io/Codesphere-Academy/
## Features

- Fully responsive design (Desktop, Tablet & Mobile)
- Shared navigation bar and footer
- Light/Dark mode with saved preference
- Mobile navigation menu
- Scroll animations
- FAQ accordion
- Contact form with client-side validation
- Back-to-top button
- Clean and modern UI
- SEO-friendly HTML structure
